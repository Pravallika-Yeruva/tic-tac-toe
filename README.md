# Tic Tac Toe

A responsive Tic Tac Toe game built with Angular. Play against the computer or
take turns with a friend.

## Development

Install dependencies and start the local development server:

```bash
npm ci
npm start
```

Run the tests and create a production build:

```bash
npm test -- --watch=false
npm run build -- --configuration production
```

The GitHub Pages deployment is published at
https://pravallika-yeruva.github.io/tic-tac-toe/.
